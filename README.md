# WatchTogether 🎬

Сервис для совместного синхронного просмотра видео с друзьями в реальном времени.

## ✨ Возможности

- **Темный минималистичный интерфейс** с шрифтом Inter и адаптивностью под любые экраны.
- **Вход по простому коду**: введите короткий код (например, `WT-789` или `CINEMA`) или создайте новую комнату в 1 клик.
- **Умный видеоплеер**:
  - Поддержка **YouTube**, **RuTube**, **VK Видео**, прямых трансляций HLS (**`.m3u8`**), файлов **`.mp4`** / **`.webm`**, и веб-страниц.
  - Автоматическое определение сервиса и встроенный парсер на базе `yt-dlp`.
  - Выбор качества видео (1080p, 720p, 480p, Auto) и озвучки / аудиодорожки.
  - Единая панель управления (таймлайн, громкость, полноэкранный режим, скорость 0.5x–2x).
- **Мгновенная синхронизация**:
  - Точная синхронизация времени, паузы и перемотки между всеми участниками комнаты через WebSockets.
  - Компенсация рассинхрона (drift correction) и кнопка ручной синхронизации.
  - Режим «Только хост может управлять» для защиты от нежелательных действий.
- **Авторизация через Telegram**:
  - Поддержка Telegram OAuth v2 (OpenID Connect) с сохранением имени и аватара.
  - Быстрый гостевой вход для тех, кто не хочет авторизоваться.
- **Живой чат**:
  - Сообщения в реальном времени, всплывающие эмодзи-реакции над видео, системные оповещения о действиях (пауза, перемотка, сменил видео).
  - Список онлайн-участников со статусом хоста и Telegram-вейджем.

## 🚀 Установка и запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка переменных окружения
Скопируйте `.env.example` в `.env`:
```bash
cp .env.example .env
```
Укажите ваши значения в `.env`:
```env
PORT=7788
NODE_ENV=production
DOMAIN=watch-together.nlpha.shop
BASE_URL=https://watch-together.nlpha.shop
SESSION_SECRET=your_super_secret_key

TELEGRAM_CLIENT_ID=your_client_id
TELEGRAM_CLIENT_SECRET=your_client_secret
```

### 3. Запуск сервера
```bash
npm start
```
Для разработки с автоперезагрузкой:
```bash
npm run dev
```

## 🔄 Автодеплой на сервере

На сервере настроен скрипт автодеплоя:
```bash
bash /opt/watch-together/deploy.sh
```
Скрипт автоматически:
1. Затягивает последние изменения из репозитория GitHub через SSH.
2. Устанавливает/обновляет зависимости npm и yt-dlp.
3. Перезапускает systemd-сервис `watch-together`.
4. Мгновенно перезагружает Nginx в Docker без перезапуска остальных сервисов.
